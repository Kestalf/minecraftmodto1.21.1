# Future Backport (Minecraft 1.21.1, NeoForge)

Мод переносит в **Minecraft 1.21.1** контент из всех последующих релизов — от 1.21.2 до **26.3**
(последняя версия на данный момент): бледный сад, медный век, счастливого гаста, копья, серные пещеры,
тополиный лес и т. д.

> Mod for Minecraft 1.21.1 (NeoForge) that backports content from every later release up to 26.3.

## Как собрать

Нужна **JDK 21**. Python и прочее не требуется.

```bash
./gradlew build          # готовый мод: build/libs/futurebackport-1.21.1-<версия>.jar
./gradlew runClient      # запустить игру с модом
./gradlew runServer      # запустить сервер
./gradlew runData        # перегенерировать рецепты/лут/теги (src/generated)
```

Положите jar из `build/libs` в папку `mods` установки с NeoForge 21.1.x для Minecraft 1.21.1.

### Откуда берутся текстуры, звуки и переводы

В репозитории **нет** ассетов Mojang. При сборке задача `importVanillaAssets` (см. `buildSrc/`)
один раз скачивает официальный клиент 26.3 с серверов Mojang (кэш в `~/.gradle/caches/futurebackport-vanilla`)
и извлекает из него только то, чего нет в 1.21.1:

* текстуры, модели блоков/предметов и blockstates (пространство имён `minecraft:` → `futurebackport:`);
* звуки новых событий и `sounds.json`;
* официальные переводы новых названий (русский и ещё ~20 языков);
* то, что в новых версиях устроено иначе, конвертируется (например, текстуры табличек 32×32 → формат 1.21.1 64×32,
  описания моделей предметов 1.21.4+ → модели 1.21.1).

Что и как импортируется, настраивается в `vanilla-assets.json`. Собранный jar содержит ассеты Mojang — он для личного
использования; перед публикацией мода учитывайте правила Mojang.

## Устройство проекта

* `src/main/java/.../registry` — регистрация блоков, предметов, звуков, частиц;
* `src/main/java/.../block` — блоки (семейства дерева/камня/меди, растения);
* `src/main/java/.../datagen` — генерация рецептов, таблиц лута, тегов, data maps, фич мира;
* `src/main/lang` — собственные строки мода (сливаются с официальными переводами при импорте);
* `buildSrc` — импорт ванильных ассетов.
